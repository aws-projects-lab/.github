## O que é essa organização?

Seja bem-vinda! Esta é uma organização open source criada **por uma mulhere, para mulheres** que estão dando os primeiros passos em AWS. Especialmente quem está se preparando para a certificação **DEA-C01 (AWS Certified Data Engineer Associate)**.

Aqui você encontra projetos reais, com **issues abertas** esperando por você. Sem julgamento, sem pressão, só prática e comunidade.

> Entender AWS de verdade não acontece só lendo documentação.  
> Acontece quando você abre um repositório, pega uma issue e coloca a mão na massa.

---

## Por que projetos abertos com issues?

Contribuir para projetos reais é uma das formas mais eficientes de aprender e também de construir portfólio. Mas muitos espaços open source podem ser intimidadores para quem está começando.

Aqui é diferente. As issues são rotuladas por nível, os repositórios têm documentação clara e a comunidade está aqui para apoiar. Se você nunca abriu um pull request antes, este é o lugar certo para fazer o primeiro.

## Foco: DEA-C01

Os projetos desta organização cobrem os domínios da certificação **AWS Certified Data Engineer – Associate**:

| Domínio | O que você pratica |
|--------|-------------------|
| ☁️ **Data Ingestion & Transformation** | S3, Glue, Lambda, Kinesis, DMS |
| 🗄️ **Data Store Management** | RDS, DynamoDB, Redshift, Lake Formation |
| 🔁 **Data Operations & Support** | CloudWatch, Step Functions, EventBridge |
| 🔐 **Data Security & Governance** | IAM, KMS, Lake Formation permissions, tagging |

## Como participar

1. Explore os repositórios abaixo
2. Vá até a aba **Issues** do repositório que te interessar
3. Escolha uma issue com a label `good first issue` ou `iniciante`
4. Comente na issue dizendo que quer trabalhar nela
5. Faça um fork, resolva e abra um pull request

Não sabe por onde começar? Leia o `CONTRIBUTING.md` ele foi feito pensando em quem está chegando agora.

## Para quem é esse espaço?

- Mulheres que estão estudando para o **DEA-C01**
- Iniciantes em AWS que querem praticar em projetos reais
- Quem ainda não contribuiu para open source e quer começar com segurança
- Mulheres que vieram de Excel, BI ou áreas correlatas e estão migrando para dados em nuvem

> ⚠️ **Este é um espaço exclusivo para mulheres.** Isso inclui mulheres trans e pessoas não-binárias que se identificam com esse espaço.
